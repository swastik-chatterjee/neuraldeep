# NeuralDeep
An AI-powered automated deep-dive generator. 

## Features
- Automated research using Tavily.
- Intelligent synthesis using Llama-3.1 via Groq.
- Real-time streamed UI for immediate insights.

## Quick Start
1. Clone the repo.
2. Create a `.env` file with `TAVILY_API_KEY` and `GROQ_API_KEY`.
3. Run `bun install` and `bun run dev`.
